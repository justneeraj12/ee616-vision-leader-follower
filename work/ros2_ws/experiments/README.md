# Experiments

Each approved experiment will receive a versioned configuration, recorded seed where applicable, acceptance criteria, and a machine-readable result summary.

Current post-freeze development protocols:

- `configurable_console_gate/experiment.yaml` records the dashboard profiles,
  initial pass/fail results, evidence boundary, and required repeated matrix.
- `convoy_governance_gate/experiment.yaml` defines the pair-first governance,
  command-dropout, incremental-chain, resource, and diagnostic checks. Its
  accepted evidence is stored separately from the frozen Gate 1--7 results.
